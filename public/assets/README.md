# Recursos visuais

- `characters/lino/`, `yume/`, `raijin/`, `kitsune/`, `shin/`, `kenji/`: portraits e logos de cada personagem, com nomes legíveis.
- `characters/_reserved/`: artes fornecidas que ainda não possuem personagem atribuído. O portrait reservado aparece na galeria como conteúdo em desenvolvimento.
- `maps/`: prévias dos mapas usadas pela interface.
- `ui/`: ilustrações dos cartões de notícias.

As referências de cada personagem são configuradas em `src/characters/<id>/presentation.ts`. Notícias e recursos do menu são configurados em `src/ui/menu/config.ts`.

Capturas de testes não ficam aqui: são geradas em `artifacts/browser/`. A prévia de Shōtō é uma exceção porque é uma imagem distribuída com o jogo.

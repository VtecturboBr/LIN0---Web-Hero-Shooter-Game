# 26. FILOSOFIA DO SISTEMA DE PODER

Uma regra importante do projeto:

**personagens não devem ter apenas "poderes legais".**

O poder deve contribuir para sua identidade.

Idealmente, habilidades refletem alguma combinação de:

- personalidade;
- história;
- trauma;
- desejo;
- natureza;
- experiência;
- relação com sua fonte de poder.

Isso também impede que todos os personagens pareçam clones funcionais uns dos outros.

---
# 27. VARIEDADE DE PODERES

O sistema deve permitir personagens completamente diferentes.

Um personagem pode vencer através de:

- força;
- técnica;
- inteligência;
- tecnologia;
- arma;
- estratégia;
- poder sobrenatural;
- treinamento;
- experiência;
- combinação de recursos.

**Não é necessário possuir um demônio para ser poderoso.**

Essa é uma regra importante para a expansão futura do elenco.
